프로그 베이비 소리 녹음

영화에 나오는 해설, 퀴즈 문제, 칭찬 말을 하나씩 녹음합니다. 목록은 장면 순서로 나오고 아직 녹음하지 않은 첫 말에서 시작합니다. 녹음은 이 브라우저에 저장되니 여러 번에 나눠서 해도 됩니다. 일부만 올려도 되고, 녹음이 없는 말은 영화에서 기기 음성으로 대신 나옵니다.

  • 조용한 방에서, 입과 마이크 사이를 한 뼘 정도로 두세요.
  • 처음부터 끝까지 같은 목소리, 같은 속도로 맞춰 주세요. 앞뒤 빈 소리와 음량은 도구가 자동으로 맞춥니다.
  • 사람 목소리 대신 AI 목소리로 채워도 됩니다. 아래 AI 목소리 설정을 한 번만 해 두면, 말마다 AI 목소리를 만들어 들어 보고 저장할 수 있어요. AI로 저장한 말도 나중에 녹음하면 사람 목소리로 바뀝니다.
  • 단축키: 스페이스 녹음 시작과 끝, P 다시 듣기, → 다음, ← 이전, A AI 목소리 만들기, S AI 목소리 저장
사람 목소리로 녹음할 때만 필요해요.

AI 목소리 설정

모델마다 하루 한도와 분당 한도가 따로 있어요. 한 모델이 하루 한도에 걸리면 다른 모델로 바꾸고 이어서 채우면 됩니다. 한도는 태평양 시간 자정(인디애나 새벽 3시쯤)에 다시 채워집니다.

API 키 받는 법 (한 번만)
  1. aistudio.google.com 에 Google 계정으로 로그인합니다.
  2. 왼쪽 아래 Get API key를 누르고 Create API key로 키를 만듭니다.
  3. 많이 만들 때는 무료 한도에 금방 걸릴 수 있어요. 그럴 때는 같은 화면에서 결제(유료 등급)를 켜면 됩니다. 한도에 걸리면 도구가 잠깐 기다렸다가 다시 시도합니다.
  4. 키를 위 칸에 붙여 넣고 저장합니다. 키는 이 브라우저에만 남고, 코드나 저장소, 내려받는 zip에는 들어가지 않습니다.

빈 말 한꺼번에 채우기

아직 소리가 없는 말을 AI 목소리로 차례대로 만들어 저장합니다. 분당 한도에 맞춰 천천히 진행돼요.

사이트에 올리기

zip을 내려받아 풀면 audio 폴더가 나옵니다. 그 폴더 안의 파일을 GitHub 저장소의 audio 폴더에 올려서 덮어쓰면 영화가 바로 새 목소리로 나옵니다. 사이트에 이미 올라가 있는 소리도 함께 들어가니 안심하고 덮어써도 돼요.
